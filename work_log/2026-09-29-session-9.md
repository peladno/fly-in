## 2. Architecture & Design Decisions

- **Standard CLI Ingestion with `argparse`:**
  - Used standard library `argparse.ArgumentParser` to automatically provide `-h`/`--help` flags and positional path validation.
  - Added `--debug` flag providing verbose post-simulation telemetry (total turn counts) without cluttering standard protocol output.
  - *Rationale:* Conforms to 42 CLI design expectations while keeping production simulation outputs completely clean.

- **Non-Crashing Error Handling:**
  - Wrapped pipeline within granular `try/except` capturing `MapParserError` and general domain exceptions.
  - Emitted user-friendly error messages to `sys.stderr` and exited with return code `1` (`sys.exit(1)`).
  - *Rationale:* Eliminates ugly Python stack traces when invalid input maps or non-existent files are provided.

- **Dynamic `sys.path` Root Anchor:**
  - Added `sys.path.insert(0, ...)` dynamically resolving project root directory.
  - *Rationale:* Guarantees smooth execution whether invoked via module syntax (`python -m src.main`) or direct script execution (`python src/main.py` / `make run MAP=...`).
