## 2. Architecture & Design Decisions

- **Layered Architecture (Clean Architecture / Separation of Concerns):**
  - Divided code into `model/` (pure entities & invariants), `parser/` (input reading & validation), `pathfinding/` (graph search algorithms without external graph libraries), and `simulation/` (discrete turn-based simulation engine).
  - *Rationale:* Strictly enforces the Single Responsibility Principle (SRP) and facilitates isolated unit testing as required by 42 standards.

- **`ZoneType` as an `Enum`:**
  - Defined an `Enum` for the four valid zone types (`NORMAL`, `BLOCKED`, `RESTRICTED`, `PRIORITY`).
  - *Rationale:* Eliminates typos from raw string literals and enables static type enforcement via `mypy`.

- **Occupancy Tracking with `set[Drone]` in `Zone`:**
  - Used a hash set to store current drones occupying the zone.
  - *Rationale:* Ensures $O(1)$ lookups, insertions, and removals, while naturally preventing duplicate entries of the same drone in a zone.

- **Infinite Capacity for Start and End Hubs:**
  - Modeled `max_drones: int | None`, where `None` indicates unbounded capacity.
  - In `is_full()`, if `max_drones is None`, it returns `False` immediately; if `BLOCKED`, it returns `True`.

- **`__repr__` and `__str__` Methods:**
  - `__repr__` produces technical debug output including name and zone type, simplifying route inspection.
  - `__str__` returns only the zone name to seamlessly integrate into the simulator output format (`D1-zoneA`).
