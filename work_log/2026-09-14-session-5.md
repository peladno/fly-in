## 2. Architecture & Design Decisions

- **Selective Metadata Token Slicing:**
  - Passed `tokens[3:]` to `_parse_metadata` so name and coordinates are excluded from key-value splitting.
  - Handled `zone=<type>`, `max_drones=<num>`, and allowed visual `color=<val>` attribute without polluting domain model physics.
  - *Rationale:* Decouples zone identifier and spatial parameters from optional configuration properties.

- **Connection Directive Ingestion:**
  - Designed `_parse_connection` to validate hyphenated link format (`zone_a-zone_b`).
  - Verified that both endpoints exist in `graph.zones` before constructing `Connection`, raising `UnknownZoneError` on dangling references.
  - Extracted bracketed `max_link_capacity=[<num>]` and ensured positive integer bounds.

- **Explicit Package API (`__init__.py`):**
  - Configured `src/model/__init__.py` and `src/parser/__init__.py` with relative imports and `__all__` lists.
  - *Rationale:* Provides clean single-line imports across the project (`from src.model import Graph, Zone`).
