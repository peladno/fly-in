## 2. Architecture & Design Decisions

- **Single Responsibility Principle in Simulation:**
  - Separated turn execution logic (`SimulationEngine`) from standard output formatting (`SimulationReporter`).
  - *Rationale:* Keeps the simulation engine focused on state transitions and capacity invariants while isolating string generation and console printing.

- **Trailing-Space Free Formatting (`str.join`):**
  - Utilized `" ".join(...)` in `SimulationReporter.report_turn` over manual concatenation.
  - *Rationale:* Eliminates trailing whitespace violations frequently flagged in automated 42 evaluations.

- **Discrete Drone Target Tracking:**
  - Initialized `self.drone_targets: dict[Drone, list[Zone]]` storing slices `paths[0][1:]`.
  - Obviated index 0 (`start_hub`) because drones are born already positioned at `start_hub`.
  - Initialized each drone with an independent slice copy (`list(...)`) to maintain isolated route states.
