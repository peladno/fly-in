## 2. Architecture & Design Decisions

- **Strategy Pattern for Pathfinding:**
  - Defined abstract base class `Router(ABC)` specifying `find_paths(graph: Graph) -> list[list[Zone]]`.
  - Concrete implementation `BFSRouter` inherits from `Router`.
  - *Rationale:* Decouples algorithm selection from consumer simulation logic, allowing easy future swapping (e.g. Dijkstra, Suurballe, or Edmonds-Karp flow).

- **Double-Ended Queue (`collections.deque`) in BFS:**
  - Queued exploratory route snapshots `deque([[start_hub]])`.
  - Used `popleft()` for $O(1)$ dequeuing and extended paths via `current_path + [neighbor]`.
  - Maintained `visited: set[Zone]` to prevent cyclical loops and bypassed `ZoneType.BLOCKED` zones.

- **Metadata Token Sanitization in Parser:**
  - Added `.strip("[]")` to incoming metadata tokens in `MapParser._parse_metadata`.
  - *Rationale:* Robustly accepts both `[color=blue]` and `color=blue` formats found across test fixtures.
