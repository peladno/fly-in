## 2. Architecture & Design Decisions

- **Custom Adjacency Representation:**
  - Designed `Graph` with an internal mapping `self.adjacency: dict[Zone, list[Connection]]`.
  - Stored zones indexed by string key (`self.zones: dict[str, Zone]`) to ensure $O(1)$ lookups during map parsing.
  - *Rationale:* Eliminates third-party graph dependencies (`networkx`, `graphlib`) while providing optimal traversal performance for pathfinding.

- **Bidirectional Adjacency Registration:**
  - In `add_connection`, the connection is appended to the adjacency lists of both endpoints (`zone_a` and `zone_b`).
  - *Rationale:* Facilitates uniform neighbor lookups via `get_neighbors(zone)` regardless of the direction the connection was originally declared in the `.map` file.

- **Avoiding Mutable Default Arguments in `__init__`:**
  - Initialized `zones`, `connections`, and `adjacency` inside the `__init__` body rather than as default parameter values.
  - *Rationale:* Avoids the Python pitfall where mutable default containers are shared across instances.

- **Graph Validation Logic (`validate`):**
  - Verifies that `nb_drones > 0`.
  - Ensures both `start_hub` and `end_hub` are present (`is not None`).
  - Confirms `start_hub != end_hub`.
