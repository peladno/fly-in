## 2. Architecture & Design Decisions

- **Iterative BFS Multi-Path Discovery:**
  - Decomposed BFS pathfinding into a core helper `_find_single_path(graph, excluded_zones)` and an iterative coordinator `find_paths(graph)`.
  - On each iteration, the router extracts the shortest available path, registers intermediate zone usage, and excludes zones once their capacity is reached.
  - *Rationale:* Allows the fleet to leverage parallel avenues simultaneously without collisions or over-subscription.

- **Intermediate Zone Capacity Tracking (`zone_usage`):**
  - Tracked usage frequencies in `zone_usage: dict[Zone, int]` via `zone_usage.get(zone, 0) + 1`.
  - When usage meets or exceeds `zone.max_drones` (defaulting to 1 if unspecified), the zone is appended to `excluded_zones`.
  - *Rationale:* Resolves infinite loop bugs on maps with intermediate nodes having `max_drones > 1` (such as `maps/easy/03_basic_capacity.txt`), while properly exhausting multi-capacity channels.

- **Fleet Path Assignment via Round-Robin:**
  - In `SimulationEngine.__init__`, drones are assigned routes using `assigned_path = self.paths[(i - 1) % len(self.paths)]`.
  - Drone targets slice out the starting hub (`assigned_path[1:]`) so drones immediately target their next waypoint.
  - *Rationale:* Balances traffic across all discovered alternate routes from the very first turn.

## 5. Challenges, Blockers & Lessons Learned
- **Infinite Loop with Intermediate Capacities:** Initially, zones with `max_drones > 1` were never marked for exclusion, causing the while loop to query the same path indefinitely. Introducing `zone_usage` with `.get(zone, 0)` safely tracks consumption until limits are met.
- **Dictionary Access Idioms in Python:** Reviewed differences between `dict.get(key, default)` (returns default when key is missing, avoiding `KeyError`) vs `dict[key]` (raises `KeyError` when absent), as well as use cases for `collections.defaultdict(int)`.
