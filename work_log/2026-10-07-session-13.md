## 2. Architecture & Design Decisions

- **Active Connection Lookup in `Graph`:**
  - Added `Graph.get_connection(zone_a, zone_b) -> Connection | None`.
  - Iterates over `self.adjacency.get(zone_a, [])` using `conn.connects(zone_b)`.
  - *Rationale:* Retrieves the singleton `Connection` instance created during map parsing (which holds configured `max_link_capacity`), rather than creating duplicate unconfigured objects.

- **Per-Turn Connection Capacity Tracking (`link_usage`):**
  - Instantiated `link_usage: dict[Connection, int] = {}` at the start of each `step()`.
  - Determined link capacity: `conn_limit = conn.max_link_capacity if (conn and conn.max_link_capacity is not None) else 1`.
  - Evaluated link availability: `link_available = (conn is None) or (link_usage.get(conn, 0) < conn_limit)`.
  - Incremented `link_usage[conn]` upon both normal traversals and restricted departures.
  - *Rationale:* Satisfies Chapter VII.2 and VII.3 mandates preventing simultaneous over-subscription of bidirectional links.

- **Full Restricted Zone Departure in Phase 2:**
  - Evaluated both destination space reservation (`len(next_zone.drones) + inbound < limit`) and link availability (`link_available`).
  - Upon starting transit: drone leaves current zone, sets `steps_remaining = 1` and `target_zone = next_zone`, and emits `D<ID>-<origin>-<dest>`.
  - *Rationale:* Conforms strictly to 42 Fly-in protocol where drones must not stall on connections and must land on the subsequent turn.
